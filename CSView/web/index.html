Parser notes

    Paste a share code and the viewer finds the demo itself: it searches every CS2 replay folder on this machine, across all Steam libraries, and matches on the id in the filename. So if the match is one you have downloaded in CS2 under Watch → Your Matches, it just opens.

    If it is not downloaded yet there is nothing the viewer can do on its own. A share code holds only a match id, an outcome id and a token — no link — and only the CS2 game coordinator can turn one into a URL, which needs a logged-in Steam session. Click Download in CS2 and paste the code again, or register a file or URL yourself with cs2mv add.
